# Inform-tica-II_ProyectoFinal
Videojuego 2D en C++ y Qt Creator donde Tarzán recrea la histórica travesía de Kapax (1976) nadando por el río Magdalena. En 2 niveles, el jugador enfrenta corrientes, rápidos y fauna salvaje desde el Huila hasta el Caribe. Proyecto enfocado en Programación Orientada a Objetos, memoria dinámica e interfaces de usuario (GUI).
